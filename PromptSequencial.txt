# PROJECT: VoiceBridge AI — Real-Time Accessibility & Interview Co-Pilot

## 1. Objective & Context
Build a low-latency, local-first Windows desktop accessibility and communication assistant in Python for **Yago Santos Silva**. The application helps a non-native English speaker participate smoothly in live technical interviews (Teams/Meet/Zoom) and record pitch videos without breaking eye contact or freezing on spoken English phrasing.

## 2. Target Hardware & Environment
- **Device:** Lenovo LOQ 15 (Windows 11)
- **CPU / RAM:** Intel Core i5 | 16GB DDR5 RAM
- **GPU:** NVIDIA GeForce RTX 2050 (4GB VRAM — CUDA enabled)
- **Constraint:** Must fit comfortably within 4GB VRAM alongside browser/video call apps (use quantized `int8`/`float16` models and lightweight inference).

## 3. Core Functional Modules
1. **Stealth Top-Center Teleprompter Overlay (`ui/overlay.py`):**
   - Frameless, translucent dark overlay (`PyQt6` or `CustomTkinter`) pinned `Always on Top` directly beneath the physical webcam bezel.
   - Supports hotkeys (`Ctrl+Shift+Space` to Pause/Resume, `Ctrl+Shift+Up/Down` for scroll speed/font size, `Ctrl+Shift+H` to hide/show).
   - **Click-through / Screen-share invisibility option:** Use Windows API (`SetWindowDisplayAffinity` with `WDA_EXCLUDEFROMCAPTURE`) so the teleprompter is visible to Yago on screen, **but completely invisible if Yago shares his screen** during a live coding or accessibility audit test.
2. **Dual-Channel Audio Capture (`audio/capture.py`):**
   - **Mic Channel:** Captures Yago's spoken English (`sounddevice` / `pyaudio`) to drive voice-activated text highlighting and auto-scrolling.
   - **System Loopback Channel (WASAPI):** Captures the interviewer's audio from Teams/Meet/Browser using `PyAudioWPatch` (Windows WASAPI loopback) without needing virtual audio cables.
3. **Real-Time Speech-to-Text & Voice Tracking (`ai/transcriber.py`):**
   - Uses `faster-whisper` (`tiny.en` or `base.en` with `compute_type="int8_float16"` on CUDA, fallback to `int8` on CPU).
   - Tracks Yago's spoken words against the loaded script using fuzzy matching (`rapidfuzz`) to highlight the current word and smoothly advance the scroll.
4. **Live Interview Co-Pilot / Answer Generator (`ai/copilot.py`):**
   - Transcribes the interviewer's question from the WASAPI loopback stream.
   - Sends context + Yago's technical profile (ADS student at Senac, PICTA Accessibility Researcher WCAG 2.1/2.2 & NVDA, LATAM Airlines SGSO 2 yrs, Python/Flutter/Java) to a fast LLM API (**Groq API** `llama-3.3-70b-versatile` or **Google Gemini Flash API** for <500ms latency) to stream concise, natural spoken-English bullet points onto the teleprompter overlay.
5. **Eye-Contact & Virtual Camera Pipeline (`vision/camera.py`):**
   - Optional lightweight OpenCV + MediaPipe Face Mesh gaze-smoothing module outputting to `pyvirtualcam` (OBS Virtual Camera), OR seamless compatibility with **NVIDIA Broadcast Eye Contact** running natively on the RTX 2050.

## 4. Open-Source Reference Repositories (Atlas for Reuse & Reverse Engineering)
The agent should inspect, adapt, or benchmark patterns from these proven architectures:
- **Real-time Whisper + WASAPI Loopback:** `ufal/whisper_streaming` and `collabora/WhisperLive` (chunked VAD + low-latency transcription).
- **Live Interview / Meeting AI Overlay:** `roy-jingyang/Interview-Copilot` and `Ilan-K/ecoute` (dual mic + system audio transcription + live LLM answer overlay).
- **Gaze Correction / Eye Contact:** `google-ai-edge/mediapipe` (Iris landmark tracking) and `NVIDIA Broadcast SDK` integration.
- **Windows Capture Exclusion (`WDA_EXCLUDEFROMCAPTURE`):** `ctypes.windll.user32.SetWindowDisplayAffinity` patterns for stealth accessibility overlays.
